## MDM Installers Global Expansion

This massive pull request transforms the repository into a globally scalable, top-tier hub for MDM scripts.

**Key Accomplishments:**
1. **Top 10 MDM Platforms:** Added dedicated guides for Intune, Jamf, Kandji, Workspace ONE, Mosyle, Hexnode, Meraki, JumpCloud, Addigy, and ManageEngine.
2. **Standardized Architecture:** Scripts have been refactored to be perfectly idempotent, including unified system logging (`/var/log/` and `C:\ProgramData\`) through common helper libraries.
3. **Data-Driven Build Engine:** Replaced static hand-coded scripts with a scalable Python build engine that generates consistent scripts from a single `apps.json` registry.
4. **500 Real-World Enterprise Apps:** We successfully researched and instantiated exactly 500 fully qualified enterprise applications across macOS and Windows, automatically scaffolding 1,000 deployment scripts instantly.
5. **Security Audit & Linting:** Scanned the repository for secrets (replaced with `PASTE_YOUR_URL_HERE`), purged toxic Git history, and configured robust CI linting using `shellcheck` and `Invoke-ScriptAnalyzer`.
