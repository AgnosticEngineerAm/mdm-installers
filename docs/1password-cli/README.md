# 1Password CLI MDM Deployment Guide

## Platforms Supported
- ✅ **macOS**: PKG
- ✅ **Windows**: EXE

## Installation Scripts
- macOS Install Script: `scripts/macos/1password-cli/install.sh`
- Windows Install Script: `scripts/windows/1password-cli/install.ps1`

## MDM Deployment Notes
Ensure you replace the placeholder URLs in the installation scripts before deploying via MDM.
