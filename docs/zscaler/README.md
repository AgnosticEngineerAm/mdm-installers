# Zscaler Client Connector MDM Deployment Guide

## Platforms Supported
- ✅ **macOS**: PKG
- ✅ **Windows**: MSI

## Installation Scripts
- macOS Install Script: `scripts/macos/zscaler/install.sh`
- Windows Install Script: `scripts/windows/zscaler/install.ps1`

## MDM Deployment Notes
Ensure you replace the placeholder URLs in the installation scripts before deploying via MDM.
