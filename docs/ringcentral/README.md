# RingCentral MDM Deployment Guide

## Platforms Supported
- ✅ **macOS**: DMG
- ✅ **Windows**: MSI

## Installation Scripts
- macOS Install Script: `scripts/macos/ringcentral/install.sh`
- Windows Install Script: `scripts/windows/ringcentral/install.ps1`

## MDM Deployment Notes
Ensure you replace the placeholder URLs in the installation scripts before deploying via MDM.
