# GitHub Desktop MDM Deployment Guide

## Platforms Supported
- ✅ **macOS**: ZIP
- ✅ **Windows**: MSI

## Installation Scripts
- macOS Install Script: `scripts/macos/github-desktop/install.sh`
- Windows Install Script: `scripts/windows/github-desktop/install.ps1`

## MDM Deployment Notes
Ensure you replace the placeholder URLs in the installation scripts before deploying via MDM.
