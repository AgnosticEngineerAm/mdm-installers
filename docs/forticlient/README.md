# FortiClient MDM Deployment Guide

## Platforms Supported
- ✅ **macOS**: DMG
- ✅ **Windows**: EXE

## Installation Scripts
- macOS Install Script: `scripts/macos/forticlient/install.sh`
- Windows Install Script: `scripts/windows/forticlient/install.ps1`

## MDM Deployment Notes
Ensure you replace the placeholder URLs in the installation scripts before deploying via MDM.
