# Jamf Connect MDM Deployment Guide

## Platforms Supported
- ✅ **macOS**: PKG
- ✅ **Windows**: MSI

## Installation Scripts
- macOS Install Script: `scripts/macos/jamf-connect/install.sh`
- Windows Install Script: `scripts/windows/jamf-connect/install.ps1`

## MDM Deployment Notes
Ensure you replace the placeholder URLs in the installation scripts before deploying via MDM.
