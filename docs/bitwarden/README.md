# Bitwarden MDM Deployment Guide

## Platforms Supported
- ✅ **macOS**: DMG
- ✅ **Windows**: EXE

## Installation Scripts
- macOS Install Script: `scripts/macos/bitwarden/install.sh`
- Windows Install Script: `scripts/windows/bitwarden/install.ps1`

## MDM Deployment Notes
Ensure you replace the placeholder URLs in the installation scripts before deploying via MDM.
