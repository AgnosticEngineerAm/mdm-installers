# Docker Compose MDM Deployment Guide

## Platforms Supported
- ✅ **macOS**: ZIP
- ✅ **Windows**: EXE

## Installation Scripts
- macOS Install Script: `scripts/macos/docker-compose/install.sh`
- Windows Install Script: `scripts/windows/docker-compose/install.ps1`

## MDM Deployment Notes
Ensure you replace the placeholder URLs in the installation scripts before deploying via MDM.
