# Google Cloud SDK MDM Deployment Guide

## Platforms Supported
- ✅ **macOS**: PKG
- ✅ **Windows**: EXE

## Installation Scripts
- macOS Install Script: `scripts/macos/google-cloud-sdk/install.sh`
- Windows Install Script: `scripts/windows/google-cloud-sdk/install.ps1`

## MDM Deployment Notes
Ensure you replace the placeholder URLs in the installation scripts before deploying via MDM.
